# Reporting (Analyst skill)

Every report follows the same spine: goal, strategy, execution,
result.

- Numbers come only from the metrics store; the narrative may
  interpret them but never add to them.
- Compare against the period's own goal before comparing
  against the previous period.
- Name what the result changes: the next period's plan must be
  visibly different because of this report, or say why it is
  not.
- Write for the owner: plain language, the decision first,
  the evidence after.
