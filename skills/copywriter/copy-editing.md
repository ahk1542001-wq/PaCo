# Copy editing (Copywriter skill)

Before hand-up, read the draft aloud and fix:

- Chopped fragments: every sentence complete and connected, with
  a soft ending. A list of blunt fragments reads rude; rewrite
  as flowing sentences.
- Repetition of the same word or structure in nearby lines.
- Any phrase the reader must decode: if a shop owner who has
  never used the tool would pause, rewrite it plainer.
- The brand's banned phrases and voice rules from the brand
  data always win over this file.
