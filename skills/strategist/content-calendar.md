# Content calendar (Strategist skill)

- Keep a recurring weekly skeleton so the mix survives busy
  weeks: concept, explainer, reactive news, proof, scene,
  question, education.
- Fix one posting slot and keep it; consistency is a signal.
- Before planning, read the previous period: never repeat a
  topic inside the no-repeat window the brand data sets.
- Every plan item names its format and visual style at plan
  time, so production never improvises structure.
